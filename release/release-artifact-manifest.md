# ASCCpp 1.0.0 artifact manifest

The exact `v1.0.0` commit produces these immutable downloadable artifacts:

- `ASCCpp-1.0.0-source.tar.gz`;
- `ASCCpp-1.0.0-linux-x86_64-static.tar.gz`;
- `ASCCpp-1.0.0-linux-x86_64-shared.tar.gz`;
- `ASCCpp-1.0.0-docs.tar.gz`;
- `ASCCpp-1.0.0.tag`;
- `ASCCpp-1.0.0.spdx.json`; and
- `SHA256SUMS` covering every other downloadable artifact.

The source and installed packages retain all applicable libraries, public
headers, component-isolated CMake metadata, LICENSE, THIRD_PARTY_NOTICES,
and Joe--Kuo data and license. Installed packages are provider-free CPU builds;
CUDA components remain available in source as experimental providers.

Archives are inspected for unsafe members and machine-local paths. Installed
artifacts use the fixed 2026-10-19 release epoch and are independently consumed
after download. Checksums and attestations are generated by the exact-tag
workflow; no old 0.9.0 checksum is reused as 1.0.0 evidence.
