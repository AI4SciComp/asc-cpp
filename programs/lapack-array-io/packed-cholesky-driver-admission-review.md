## Frozen driver behavior

Implement S/D/C/Z QueryPpsvWorkspace/Ppsv with explicit optional provider,
mutable ordinary packed A and independent full RHS B layout. It must enter
actual native PPSV, which validates UPLO/N/NRHS/LDB, always calls PPTRF, then
calls PPTRS only after INFO0. A positive INFO j reports not-positive-definite,
zero-based index j-1 and source-defined partial factors while B is unchanged.
The upper partial publication includes completed/failed columns through j;
lower j=1 changes only the first diagonal, while later failures retain prior
trailing rank updates. Negative, missing, partial or greater-than-N INFO is
a provider defect; row publication is withheld and direct writes survive.

Zero order completes locally without numeric reads or native INFO, after all
metadata/plan/workspace checks. Positive order with zero RHS still factors A,
including its real numerical failures. It reads/writes no B numeric entries.
Row A packs p live caller T objects, reading only real complex input diagonals
as PPTRF requires; row B packs N*NRHS live T objects when nonempty. Nonempty
row B is copied before the native driver, including when factorization later
fails; this explicit conversion preserves B but is not a native conditional
read observation. Direct B follows the native factor-failure read behavior.
No hidden allocation, densification, factor certificate or blanket symmetry,
positivity or finiteness scan is added. The factor and solve equations use
A=U^H U or A=L L^H and A X=B, with real transpose equivalents.

Queries inspect metadata only and bind routine/scalar/exact provider identity,
N/NRHS/actual LDB, triangle, both layouts and original B stride. All input,
workspace, metadata and report reachable spans must satisfy existing alias,
placement, capacity/alignment and live-object contracts. Preflight precedes
numerical mutation/provider entry. Disjoint synchronous calls are reentrant;
callers exclude conflicting mutable access. No provider handler is installed.

## Source integer and progress obligations

PPSV has no data-dependent retry or workspace query. For N>0, every native
argument must fit, including actual LDB even when NRHS=0. PPTRF's source bound
always applies. With positive RHS, PPTRS additionally needs N*(N+1) to fit
before division in one of its two TPSV paths and NRHS+1 for loop exit. Empty
order stays in the ASC dimension domain, without narrowing unexecuted values.
Literal models preserve PPTRF and TPSV cursor order and scalar BLAS cleanup/
unrolled loop exits. They compare both triangle/real-complex paths on virtual
limits; no fake descriptors or gigantic allocations are used.

With zero RHS the LP64 order endpoints are 65,535 upper and 65,534 lower;
true ILP64 endpoints are 4,294,967,295 and 4,294,967,294. Positive RHS reduces
both triangles to 46,340 LP64 or 3,037,000,499 ILP64. Separate ASC descriptor
backing/byte arithmetic remains mandatory. XERBLA is unreachable only under
these checked root dimensions/flags and the previously admitted nonnegative
selected PPTRF/TPSV/DOT/SCAL/SPR/HPR arguments with increment one.

Typed adapters, independent factor reconstruction and solve residuals/forward
error, first/last non-positive minors, zero RHS factorization, every layout/
scalar/scale, malformed inputs/workspace/INFO, protected memory and allocation,
root/installed and full mode/concurrency/platform acceptance remain required.
All remaining P00-P11, 70 prior ordinary mathematical failures and 130 missing
required XBLAS routines remain visible. No full capability is claimed.
