## Frozen implementation direction

The next optional-provider overloads are QueryPptrsWorkspace/Pptrs for S/D/C/Z,
with explicit upper/lower triangle, const checked ordinary packed factors and
mutable full RHS matrix. Factor/RHS layouts are independent. Raw factors are
borrowed and reused unchanged; no automatic refactorization, factor provenance
certificate, symmetry/finiteness scan or hidden conversion is introduced.
All factor components, including complex diagonal imaginary components, belong
to the triangular factor and are read as supplied. This differs from PPTRF's
Hermitian input diagonal convention and must not reuse its real-only packing.

Upper solves U^H Y=B then U X=Y; lower solves L Y=B then L^H X=Y, using
transpose for real scalars. PPTRS itself has no positive numerical INFO case
or zero-diagonal scan. Zero factor diagonals follow native TPSV arithmetic;
INFO0 is completion, not a numerical validity certificate. Any nonzero,
unwritten or partially written INFO is a defect. Row RHS publication is
withheld on defects while direct native writes survive. Factors and RHS
padding are preserved. Query/plan/operand/workspace/report metadata checks
must precede any numeric write or provider entry; no global handler changes.

For nonempty order and RHS, both triangles execute one TPSV branch that
forms N*(N+1) before dividing by2. It must fit the provider INTEGER, as must
the final PPTRS RHS-loop value NRHS+1. That bound covers all selected p+1
packed cursors and N+1 loop controls. Pure native-count endpoints are46,340
for LP64 and3,037,000,499 for ILP64. Actual live backing/ASC byte capacity
remains independently required. The literal models include each of the four
INCX1 TPSV paths and RHS loop exit without constructing giant descriptors.

Empty order or zero RHS completes locally with absent INFO, reads neither
numeric operand, and needs no packing. Local metadata uses the ASC extent
domain without narrowing unexecuted foreign arguments. All shape, placement,
metadata alias and stale-plan checks still apply. Nonempty row factors use p
live T objects and row RHS uses N*NRHS live T objects in explicitly queried
caller storage; plan keys bind dimensions, layouts, original RHS stride and
exact routine/scalar/provider ABI. No densification is permitted.

Typed adapters, independent multiple-RHS residual/reuse and scale tests,
wrong-triangle/zero-scalar/local-empty cases, all preflight/INFO/memory/alias
observations, installed integration and full mode/platform closure remain
required. PPTRI/PPSV/PPSVX/PPCON/PPRFS/PPEQU andall other P00-P11 requirements
remain open;130 missing required XBLAS entries andold mathematical failures
remain visible. No native or fully verified routine credit is assigned.
