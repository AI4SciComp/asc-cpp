## Frozen implementation direction

Implement explicit QueryPptriWorkspace/Pptri overloads for S/D/C/Z on mutable
checked ordinary packed factors. Upper input represents U from A=U^H U;
lower represents L from A=L L^H, with transpose for real scalars. Success
replaces the factor with the selected packed triangle of A inverse. Complex
input is a Cholesky factor, whose diagonal is real; unlike Hermitian input
packing, its components must not be silently erased before native TPTRI.
Raw factors carry no provenance certificate and receive no symmetry,
finiteness, positive-diagonal or automatic refactorization scan. The inverse
equation assumes valid Cholesky factors. Arbitrary nonreal complex diagonals
follow native arithmetic without a new mathematical guarantee.

PPTRI first invokes nonunit TPTRI, which scans every selected diagonal for an
exact zero before mutation. Positive INFO j returns kNumerical/kSingular,
index j-1, and the source-defined unchanged factor; row publication is withheld.
Negative, missing, partially written or greater-than-N INFO is a provider
defect; row publication is withheld while direct native writes cannot roll
back. INFO0 reports completion, without a finiteness/conditioning certificate.
No implicit rescaling, fallback, provider patch or densification is added.

Queries inspect metadata only. Row layout needs exactly p=N*(N+1)/2 live T
objects in caller layout workspace; column layout is direct. Zero order
completes locally with absent native INFO and no numeric reads or packing.
Plans bind exact routine/scalar/provider identity, triangle, layout and order.
All shape/placement/identity/alias/workspace checks precede numeric mutation.
All borrowed objects remain live; disjoint calls are reentrant and callers
exclude conflicting mutable access. No mutable provider handler is installed.
